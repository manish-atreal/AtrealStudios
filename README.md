# AtrealStudios
A professional, high-performance corporate website built with React, Tailwind CSS, and Framer Motion. This platform showcases our services, client portfolio, company culture, and career opportunities.

🚀 Live Demo
https://www.atreal.in/

🛠 Features
🔹 Service Showcase
Detailed breakdown of our core offerings with interactive UI elements and clear value propositions.

🔹 Client Portfolio
A clean, responsive grid featuring our valued partners and clients with integrated brand identity sections.

🔹 About Us
Insight into our mission, vision, and the core values that drive our team forward.

🔹 Careers Portal
Current job openings and a glimpse into our company culture to attract top-tier talent.

🔹 Contact & Inquiry
Fully responsive contact forms and location mapping for seamless business communication.

💻 Tech Stack
Frontend: React.js
Styling: Tailwind CSS (Mobile-first responsive design)
Animations: Framer Motion (Smooth scroll and entrance effects)
Routing: React Router DOM
Icons: Lucide React / React Icons
📂 Project Structure
src/
├── components/        # Reusable UI components (Navbar, Footer, Cards)
├── pages/             # Main view components (Home, About, Services, Careers)
├── data/              # Static data files (services-data.js, clients-data.js)
├── assets/            # Images, logos, and global styles
└── App.js             # Main application entry and routing
